FEA_meg is an end-to-end computational biomechanics project for reconstructing and testing the feeding mechanics of Otodus megalodon from imaging data through finite-element analysis and publication outputs. The repository combines micro-CT/DICOM reconstruction, photogrammetry and scanning assets, watertight surface repair and TetWild tetrahedral meshing, smoothing and boundary validation, COMSOL-based static and nonlinear constitutive-model studies of teeth and jaw structures, custom solver experiments, Jupyter notebooks, HTML result dashboards, HPC workflows for NYU Greene, and LaTeX manuscript generation. In practice, it is a single workspace for moving from raw geometry and mesh preparation to stress/strain visualization, model comparison, ecological interpretation, and final paper figures for the broader megalodon biomechanics study.
